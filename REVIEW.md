| 1 | `compute_late_minutes` | Off-by-one in late condition: `minutes > 10` misses cases like 09:40:01 (10 min 1 sec) which should be late with `late_minutes = 10`. | 2 | `compute_late_minutes` | Does not truncate instants to whole seconds before calculation (R1). | Punch-in 09:40:00.900 should count as 09:40:00 (not late). Code sees 900 ms and may treat as 09:40:00.900, potentially changing late minutes. | Truncate `punch_in` to seconds (`punch_in.replace(microsecond=0)`) before any calculation. |
| 3 | `compute_work_hours` | Uses Python's `round()` which implements banker's rounding, not half-up (R4). Also does not truncate instants to whole seconds. | Work duration 2.345 hours. | 6 | `create_employee` | `created_at` uses `datetime.now()` (naive local time). DATA_MODEL requires BSON datetime UTC. API response expects epoch milliseconds. Response `created_at` is `"2026-10-12T10:30:00"` instead of an integer epoch ms. | Set `created_at = datetime.now(timezone.utc)`. **Things examined and decided *not* defects:**

- The `IST` timezone constant is correctly defined as UTC+05:30.
- The `app` title and version match the OpenAPI spec.
- The use of `load_dotenv()` is fine for local development.
- The `EmployeeIn` model includes default values for `shift_start` and `shift_end` as specified in OpenAPI.
- The `PunchInIn` model makes `punched_at` optional with default `None`, which is correct.
- The `health` endpoint returns a JSON body with `{"status": "ok"}` on success, which matches the schema (once the MongoDB ping is added).
- The `create_employee` endpoint correctly pops `_id` before returning (though other fixes are needed).
- The `list_employees` endpoint uses projection `{"_id": 0}` to exclude `_id`, which is correct.
- The `list_attendance` endpoint uses `(page - 1) * page_size` for slicing, which is correct (though the overall approach is flawed).

**Summary:** 30 distinct defects found, covering helper functions, endpoints, models, concurrency, timezone handling, pagination, validation, and performance. All will be fixed in Phase B.
